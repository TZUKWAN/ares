# ares-lab-skills E2 实验技能扩展模块

定位：不代替动手操作。产出训练与备赛辅助材料，帮助选手按官方评分表系统训练。

## 一、触发条件与输入

总控路由判定 pipeline 为 E2 时调用。输入：赛事与赛项、rubrics/NNN.json（操作评分表结构）、训练周期、现有水平自评。

## 二、执行步骤

1. 官方评分表逐项拆解：把评分表拆到动作级（如金相：磨制→抛光→腐蚀→观察四道工序各自的评分点与分值）。
2. 操作规范手册：每动作级条目按 标准动作/工具参数/合格判据/常见错误 四栏成文。
3. 常见扣分点清单：按扣分频率与分值加权排序，标注对应评分表条目编号。
4. 训练打卡计划：按训练周期排每日任务（工序+组数+自检项），周期化递进。
5. 实验报告模板：按赛事报告要求给结构化模板（含填写示例）。

## 三、输入输出契约

- 输出：01-操作规范手册.docx ｜ 02-常见扣分点清单.md ｜ 03-训练打卡计划.xlsx ｜ 04-实验报告模板.docx
- 手册条目与官方评分表条目编号可对照追溯；安全红线单独成节置顶。

## 四、质量自检清单

- [ ] 评分表逐项拆解无遗漏（条目数与官方一致）
- [ ] 每个条目四栏齐全（标准动作/工具参数/合格判据/常见错误）
- [ ] 扣分点清单含分值与频率排序依据
- [ ] 打卡计划日任务可执行、总量匹配训练周期
- [ ] 安全注意事项置顶且完整
- [ ] 写作纪律机扫通过

## 五、协作接口

调用：ares-writing-style、ares-docx、ares-judge。医学技术技能大赛等含理论考核的赛项，理论部分题库清单归 ares-humanities 协作产出。
