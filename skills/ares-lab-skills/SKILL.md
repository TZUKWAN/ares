# 实验技能训练

适用：lab / hardware。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 读取实际适用规程、器材与记录要求，安排训练和观察指标；具体操作遵守所在实验环境规范。
2. 实际操作、观察、取样和仪器测量由团队完成，保存原始记录与条件。
3. 没有实验记录时只提供训练/记录方案，不能补造实验数据、仪器截图或操作照片。
4. 区分仪器误差、操作误差和样本差异；分析基于实际记录，可提出后续验证计划。
5. 模型不能通过 ares_project complete 认证人工节点，团队在工作台结合真实记录登记。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
