# ares-simulation E3 模拟经营扩展模块

## 一、触发条件与输入

总控路由判定 pipeline 为 E3 时调用。输入：赛事与 rubrics/NNN.json（模拟规则与评分机制）、队内分工、目标名次。

## 二、执行步骤

1. 规则拆解：从 rubric 提取模拟机制（回合数/市场结构/供需弹性/破产规则/评分权重），形成规则速查表。
2. 决策模型（Excel）：定价/排产/财务联动三表联动模型——
   - 输入区：各市场定价、产能分配、原料采购、广告投入；
   - 计算区：需求估计（价格弹性）、收支与现金流推演；
   - 输出区：预计名次指标（累计利润/市场份额/现金流安全度），单元格公式透明可审计。
3. 策略手册：开局期（定位与产能卡位）/中期（扩张与价格战应对）/决胜期（利润冲刺与风险控制）三段打法，每段含关键决策表与触发条件。
4. 历史规则复盘：近几届规则变化点与应对差异。
5. 训练脚本：队内模拟对抗流程（回合脚本+复盘清单+角色分工）。

## 三、输入输出契约

- 输出：01-决策模型.xlsx（三区联动，公式完整）｜ 02-策略手册.docx ｜ 03-历史规则复盘.md ｜ 04-训练脚本.docx
- 决策模型重算结果稳定；所有假设标注 DEMO。

## 四、质量自检清单

- [ ] 规则速查表与官方规则一致（对照 rubric 逐条）
- [ ] Excel 模型公式可审计、无循环引用错误、重算一致
- [ ] 策略手册三段各有关键决策表与触发条件
- [ ] 训练脚本含回合流程与复盘清单
- [ ] 写作纪律机扫通过

## 五、协作接口

调用：ares-writing-style、ares-docx、ares-data（需求估计的参数估计）、ares-judge。学创杯（id 43）按 E3+L1 双线执行：模拟部分走本模块，商业计划书部分走 ares-entrepreneurship。
