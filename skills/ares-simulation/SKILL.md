# 模拟经营策略

适用：simulation。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 读取具体平台版本、规则、初始状态、资源约束和计分方式，不套用统一经营参数。
2. 根据各期状态比较生产、定价、营销、采购和资金策略，记录测算、假设和潜在缺口。
3. 预测、离线模拟和平台实际反馈分别登记。团队执行平台决策后才能写实际轮次结果。
4. 逐期比较预测与实际，解释需求、库存、成本和现金流偏差，不用脚本模拟当成平台成绩。
5. 输出决策依据和可复用复盘，未获平台反馈时保留待团队提供的任务。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
