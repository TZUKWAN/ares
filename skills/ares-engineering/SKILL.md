# ares-engineering L3 工科作品线

## 一、触发条件与输入

总控路由判定 pipeline 为 L3 时调用。输入：project.json、赛事 rubrics/NNN.json、作品形态（软件类/硬件类）。

## 二、执行步骤

1. 需求分析：从赛题/命题与 rubric 提取硬性指标（精度/速度/功耗/载重等），列为验收表。
2. 总体方案：2-3 套方案对比选型（含落选理由），系统框图与指标分配。
3. 详细设计：机械/电路/软件分章；软件类直接进入系统设计与实现。
4. 作品产出：软件类=可运行系统（有界面给界面原型，走 ares-prototype 规范）；硬件类=仿真（电路/结构/控制仿真）+控制端软件+结构设计说明+BOM 清单。
5. 测试方案与数据：按验收表逐项实测（或仿真）记录，与对标方案量化对比成表。
6. 技术报告成文：按默认结构，排版 ares-docx，纪律 ares-writing-style。
7. 展示 PPT 与演示视频脚本：PPT 走 ares-ppt；视频脚本按 分镜/画面/台词/时长 四栏。
8. 实物制作指引（硬件类）：器件采购清单（含参考价）、装配步骤、调试要点、安全注意。

## 三、技术报告默认结构

需求分析 → 总体方案 → 详细设计（机械/电路/软件分章）→ 创新点 → 测试方案与数据 → 结论与改进。

## 四、输入输出契约

- 输出：01-设计说明书或技术报告.docx ｜ 02-作品原型或仿真/ ｜ 03-源代码/ ｜ 04-测试数据与性能对比表.xlsx ｜ 05-展示PPT.pptx ｜ 06-演示视频脚本.docx ｜ 07-实物制作指引.docx（硬件类）｜ 08-数据真实性清单.md
- 测试数据表必须含与对标方案的量化对比列；仿真数据标 DEMO。

## 五、质量自检清单

- [ ] 硬性指标验收表逐项有数据（实测/仿真标注清楚）
- [ ] 与对标方案量化对比 ≥3 项指标
- [ ] 源代码可运行（附运行说明）；BOM 清单器件齐套
- [ ] 报告结构完整；创新点有量化佐证；写作纪律机扫通过
- [ ] 一致性扫描零矛盾；PPT 溢出检查通过

## 六、协作接口

调用：ares-writing-style、ares-docx、ares-ppt、ares-prototype、ares-data、ares-judge。命题类赛项（中国软件杯、集成电路等）先做命题解析再进入本流程。
