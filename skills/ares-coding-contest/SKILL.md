# 算法训练与复盘

适用：coding。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 默认用于训练、离线练习和复盘，先读取任务的实际使用边界；不能越过当前赛事规则。
2. 依据已有表现安排知识点、题目和难度；题目有真实来源，自编练习明确标为自编。
3. 给出适配题意的算法、正确性论证和复杂度；真实实现并运行边界、反例及规模测试。
4. 没有实际提交或评测结果时不能宣称AC、通过率或排名；不以硬编码样例输出充当算法。
5. 复盘记录错误、反例、修复和复测，不生成无关商业计划书、财务表或展示作品。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
