# 视觉与影像作品

适用：design / video。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 先区分海报、策划、产品、空间、UI、视频等作品形态，读取命题、受众和输出规格。
2. 以创意目标、素材依据、方案探索和实际制作推进；创作说明不能替代实际作品。
3. 图像、排版、动画、剪辑和音频分别使用真实可用工具。工具不存在时报告能力缺口，不宣称已生成。
4. 按素材、字体、音乐和AI使用的当届要求记录出处与使用方式；保留可编辑工程。
5. 调用 ares-design-review 检查真实作品的视觉和媒体规格。PPT、展板和文档按当前作品要求选择。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
