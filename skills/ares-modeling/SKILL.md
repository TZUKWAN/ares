# 数学与统计建模

适用：modeling。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 逐问明确目标、输入、约束、变量和输出，检查原始题面、附件及数据版本。
2. 按问题比较适用模型，解释假设和方法选择；不强制统一算法组合、对比数量或扰动幅度。
3. 调用 ares-solve 实现实际求解、保存命令和结果；调用 ares-validation 检验误差、稳定性与适用边界。
4. 代码实际输出是论文数值的来源；失败、未收敛、不可行和缺失数据不能用手填数字代替。
5. 论文语言、摘要页、匿名、篇幅和附件格式由当前命题及规则决定；不沿用无关往届任务。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
