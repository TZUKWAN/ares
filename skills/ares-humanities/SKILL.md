# 人文语言与表达

适用：humanities。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 明确演讲、翻译、写作或文本研究的体裁、目标语言、受众、语域和评阅要求。
2. 翻译核对原文语义、术语、语体和文化信息；保留原文定位和疑难处理理由。
3. 演讲组织主张、论据、节奏和口头表达，实际排练由团队提供时长与反馈；不能虚构练习效果。
4. 写作按体裁安排段落、标题、对话和修辞；不套创业文本的禁问句、固定首句字数或强制数据。
5. 核对引用与真实性，输出具体语言问题和修改依据，不编造专家评价或比赛得分。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
