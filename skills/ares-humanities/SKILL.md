# ares-humanities E1 人文语言扩展模块

## 一、触发条件与输入

总控路由判定 pipeline 为 E1 时调用。输入：赛事与赛项（演讲/辩论/写作/阅读/翻译/征文）、主题或命题、时长/字数要求（取自 rubrics）、选手水平自评。

## 二、执行步骤

1. 评分标准对照：把 rubrics 的评审维度转成可操作的自评表（后续交付给选手）。
2. 稿件创作：按稿件类型分路——
   - 演讲稿：定题破题→三段式结构（钩子/论证/升华），产出 3 分钟与 5 分钟两版，逐段加技巧批注（停顿/重音/手势/目光建议）。
   - 辩论稿：立论框架（定义/标准/论点/论据）+ 常见反驳预案。
   - 写作/译文：按赛事文体规范成稿，翻译类附翻译策略说明（直译意译取舍/文化项处理）。
   - 征文：按主题立意成文，符合赛事字数与体裁。
3. 针对性训练方案：按评分维度设计 4-8 周训练（每日/每周任务+自测标准）。
4. 评分标准对照自评表：维度/官方表述/自评要点/分值，xlsx 交付。

## 三、输入输出契约

- 输出：01-参赛稿件.docx（演讲类含 3 分钟/5 分钟两版+逐段技巧批注）｜ 02-针对性训练方案.docx ｜ 03-评分标准对照自评表.xlsx
- 外研社四赛项、21世纪杯等按 rubrics 的分赛项要求分别执行。

## 四、质量自检清单

- [ ] 稿件满足时长/字数（3 分钟约 400-450 词英文或 800-900 字中文，5 分钟按比例）
- [ ] 逐段技巧批注与稿件内容对应
- [ ] 训练方案可直接执行（任务量化、有自测标准）
- [ ] 自评表维度与官方评分维度一一对应
- [ ] 写作纪律机扫通过（英文稿件按英文写作规范另行通读）

## 五、协作接口

调用：ares-writing-style、ares-docx、ares-judge。中文类赛事（诵写讲/征文）稿件的文学性优先于纪律条款，但禁用词句纪律仍适用。
