# 按体裁组织文字

适用：所有需要文本的步骤。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 先确定当前作品的体裁、受众、章节要求和语言；官方格式与用户偏好优先。
2. 学术与技术文本重视论证和证据，商业文本重视问题、方案与可行性，人文作品按体裁表达。
3. 标题、列表、问句、引语、术语和图注按用途使用，不机械禁止，也不强制相同首句长度。
4. 所有数据、引文、成果和评价必须有真实依据；定性判断用适合的论证支持，不为配数字而虚构。
5. 删除重复与夸张，保持术语一致；区分事实、推断、预测和计划。词表扫描只能作提醒，不能替代语义复核。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
