# Ares 写作风格纪律

本技能是 Ares 全部文本产出的强制纪律层。任何生产线技能（ares-entrepreneurship、ares-modeling、ares-engineering、ares-business-case、ares-art-design、ares-humanities 等）在生成 Word 文档、论文、报告、讲稿正文时，必须先读取本文件，写完逐条自检。PPT 页内文案适用第六节专门纪律，其余场景适用通用纪律。

## 一、触发条件

- 被 ares 总控或任何生产线技能在文本生成步骤前显式引用。
- 用户要求写作/修改/润色竞赛文本类交付物。
- ares-judge 质检环节对产出文本做纪律扫描时，以本文件为唯一判定依据。

## 二、执行步骤

1. 写作前：通读第三节通用纪律与第六节 PPT 纪律（如适用），确认禁用清单。
2. 写作中：段落化表达，用数据支撑论点，遵守特殊段落首句规则。
3. 写作后：执行第五节自检清单逐条扫描，命中任何一条即重写该段；可调用 `scripts/check_style.py <文档路径>` 做机扫初筛（拦截违禁词与违禁句式），机扫通过后仍需人工通读一遍语义层面违规（如泛泛表述、无数据空论）。

## 三、通用纪律（所有学术/商业文本，强制）

1. 学术化表达，逻辑严谨，层层递进；语言平实，不夸张，易懂但用词专业，整体保持较高学术质感。
2. 禁用机械连接词：首先、其次、再次、最后、第一方面、第二方面、综上所述（收尾用自然总结句替代）、值得注意的是、不得不说、总而言之。
3. 禁用夸张吹嘘表述：重构、重建、填补空白、颠覆、革命性、全球首创、业界第一、遥遥领先。
4. 禁随意使用引号、冒号、破折号等一眼 AI 的标点。引号只用于法定名称与直接引语；冒号只在表格、图注、标题层级中使用；破折号一律改用逗号或括号。
5. 禁止任何小标题与分点罗列（章节骨架标题除外），形成段落化文本，多分自然段。计划书正文每节至少两个自然段，单段不超过 350 字。
6. 禁止举例式写法：例如、比如、举例来说、以XX为例一律不得出现（案例性内容直接陈述事实本身）。
7. 禁止提问句式：如何、何以、为何、为什么、能否、是否可以等疑问结构不得出现在正文陈述中（答辩 QA 预案的问题清单除外，那是问题集本身）。
8. 尽可能用数据说明问题：每个关键论断配数字、来源、年份；无数据支撑的定性判断一律删改。
9. 控制篇幅，不注水：删除一切不推进论证的句子；同义重复、排比堆砌视为注水。

## 四、特殊段落规则（产品优势、创新优势、竞争优势等段落，强制）

1. 每段第一句字数必须一致（各段首句字数相等，误差不超过 2 字）。
2. 各段首句语法结构一致（同一主谓宾框架）。
3. 首句是该段内容的抽象概括总结，有理论高度，表述精炼漂亮，恰当使用成语。
4. 首句之后展开具体论据与量化数据，禁止再出现概括句。
5. 组内段落数 3-5 段，每段一个优势点，不交叉重复。

## 五、自检清单（写作完成后逐条执行，命中即重写该段）

- [ ] 全文搜索：首先、其次、再次、最后、综上所述、值得注意的是、总而言之 → 0 命中
- [ ] 全文搜索：重构、重建、填补空白、颠覆、革命性、全球首创、遥遥领先 → 0 命中
- [ ] 正文搜索：如何、何以、为何、为什么（排除 QA 预案问题清单与标题）→ 0 命中
- [ ] 正文搜索：例如、比如、举例来说、以XX为例 → 0 命中
- [ ] 正文中引号仅出现在法定名称与直接引语；破折号 0 个；冒号仅存在于表格/图注/标题
- [ ] 无小标题与分点（章节骨架标题除外）；正文均为自然段
- [ ] 每个关键论断有数据、来源、年份三要素
- [ ] 特殊段落：各段首句字数一致、结构一致、抽象概括、含成语
- [ ] 无泛泛表述（任何项目都能套用的话，如 团队年轻有活力、经验丰富、技术过硬）
- [ ] 无 自嗨式估算 与 国内领先、国际先进 式空话
- [ ] 篇幅与内容密度匹配，删除注水段落

机扫工具：`python skills/ares-writing-style/scripts/check_style.py <文件.docx|md|txt> [--strict]`，退出码 0 为通过。机扫覆盖以上词表层违规；语义层（数据三要素、首句规则、成语、泛泛表述）由写作方与 ares-judge 按本清单人工判定。

机扫词表与本文档的对应关系（以 scripts/check_style.py 常量为准，含变体扩展）：
- 机械连接词：首先、其次、再次、最后、综上所述、值得注意的是、总而言之、第一/二/三方面
- 夸张吹嘘：重构、重建、填补（含填补空白/填补了行业空白等一切变体）、颠覆性、革命性、全球首创、业界第一、遥遥领先、国际首创
- 举例式写法：例如、比如、举例来说、譬如
- 泛泛表述：年轻有活力、经验丰富、技术过硬、国内领先、国际先进、国际领先、行业领先水平、有很大潜力、前景广阔、意义重大、影响深远
- 疑问字样（正文）：如何、何以、为何、为什么、怎样才能、怎么才能（QA 预案用 --allow-questions 跳过）
按文档自检时请对照上表全文搜索（含"填补了空白"这类插入变体），与机扫口径一致。

## 六、PPT 文案纪律（ares-ppt 生成页内文案时适用）

1. 每页标题是一句话，对该页内容的总结，有煽动性，简洁，最好是排比句或对仗句。
2. 所有内容必须有量化数据支撑，禁止空泛定性描述；拒绝大段文字，每页正文不超过 120 字。
3. 拒绝任何项目都能用的泛泛表述（团队年轻有活力等）；一切优势须为项目独有且与前文呼应。
4. 引用数据优先国家级行业协会、权威第三方机构公开数据，标注来源与年份；拒绝自嗨式估算与国内领先、国际先进式空话。

## 七、违规→修正对照示例

示例一（机械连接词）
- 违规：首先，市场规模持续扩大；其次，政策红利不断释放；最后，技术条件已经成熟。
- 修正：养老健康市场过去三年保持 18% 的年均增速（艾媒咨询，2025），二十项中央与地方政策在 2024 至 2025 年间密集落地，毫米波雷达模组成本同期下降 62%，需求、政策与技术三条曲线在同一时间窗口交汇。

示例二（AI 味标点与空话）
- 违规：本项目实现了三大"突破"——算法"领先"、系统"先进"、体验"一流"，填补了行业空白。
- 修正：项目识别算法在 2000 段真实场景视频集上达到 96.5% 的准确率，比对标方案高出 8.2 个百分点；单套部署成本 599 元，为市面同类产品的 43%。

示例三（特殊段落首句规则）
- 违规：我们的团队很有活力。项目技术很厉害。商业模式也特别好。
- 修正：以下三段首句等长、同构、抽象概括、含成语。
  - 段1首句：非接触感知构筑了不可复制的物理层壁垒。
  - 段2首句：多模态融合锻造了行业独有的算法层优势。
  - 段3首句：社区网络沉淀了难以撼动的数据层资产。
  （三句均为 16 字、主谓宾同构、抽象概括、含成语，其后各段展开量化论据。）

## 八、与其他技能的协作接口

- 输入：来自各生产线技能的内容要求（章节、字数、数据字段）。
- 输出：符合本纪律的段落化文本。
- 被 ares-judge 引用：质检时以第五节自检清单为判定标准，机扫结果作为证据。
- 被 ares-ppt 引用：页内文案适用第六节。
- 修改接口：收到 ares-judge 的扣分点后，仅重写违规段落，不动其余内容。

## 九、质量自检责任

生成方（写作 agent 或生产线技能）在交付前必须完成第五节自检清单并在交付说明中注明已执行；ares-judge 复检时再次扫描，双重把关。
