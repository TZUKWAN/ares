# 调查报告与商科案例

适用：survey / case-analysis。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 调查类先确认问题、抽样、变量和问卷，交给 ares-survey 设计；团队完成真实采集后再分析。
2. 案例类读取原始案例、事实时间线和约束，再选择分析框架与定量测算，不机械叠加SWOT、五力等。
3. 调用 ares-analysis 保存清洗、测算、脚本和实际结果；不存在的数据保持缺口。
4. 统计阈值、方法和样本量有研究依据；不能用合成数据冲抵调查回收或通过固定信效度门槛。
5. 建议与数据和案例约束逐条对应，说明推广边界。只在实际环境可用且赛事需要时提供SPSS等额外口径。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
