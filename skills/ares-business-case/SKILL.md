# ares-business-case L4 商科分析线

## 一、触发条件与输入

总控路由判定 pipeline 为 L4 时调用。输入：project.json、赛事 rubrics/NNN.json、作品形态（调研报告类/案例分析类）。

## 二、执行步骤

调研报告类（市调大赛等）全流程：
1. 选题：3 个候选选题按 数据可得性/现实意义/方法适配 打分选定。
2. 问卷设计：量表规范（Likert 五级、维度与题项映射表）、预调研与信效度检验说明（Cronbach α≥0.7、KMO≥0.7 目标）。
3. 抽样方案：总体/框架/方法/样本量计算式。
4. 数据生成或清洗：无真实数据时按 ares-data 合成规范（分布设定+种子固定+DEMO 标注）。
5. 建模分析：回归/聚类/因子/结构方程按选题匹配，SPSS 操作路径与 Python 脚本双口径，结论一致。
6. 结论建议：按数据逐条落建议，不含无法从数据推出的断言。
7. 成文：按官方论文格式规范（rubric deliverable_requirements）排版 ares-docx。

案例分析类（会计/税收/金融/物流）：
1. 案例背景拆解与问题识别。
2. 分析框架库选用：SWOT、波特五力、杜邦分析、平衡计分卡、风险矩阵、PEST、财务比率体系，按案例匹配 2-3 个并用透。
3. 定量测算（杜邦/税负/估值等）脚本化，过程可复现。
4. 分析报告成文 + 展示 PPT。

## 三、输入输出契约

- 输出：01-调研问卷.docx（或案例背景包）｜ 02-样本数据（合成必标 DEMO）/ ｜ 03-分析代码/ ｜ 04-分析报告.docx ｜ 05-答辩PPT.pptx ｜ 06-数据真实性清单.md
- 分析代码可运行，重跑结果一致；关键统计量回填 project.json。

## 四、质量自检清单

- [ ] 问卷维度-题项映射表齐；信效度检验说明完整
- [ ] 问卷正文含题目疑问句属正常文体，机扫时对 01-调研问卷.docx 使用 --allow-questions（题项分点同理豁免）
- [ ] 抽样方案含样本量计算式
- [ ] 分析方法与数据形态匹配；双口径结论一致
- [ ] 报告格式符合该赛事官方规范（对照 rubric 逐条）
- [ ] 合成数据 DEMO 标注；一致性扫描零矛盾；写作纪律机扫通过

## 五、协作接口

调用：ares-writing-style、ares-docx、ares-ppt、ares-data、ares-judge。统计建模类需求（id 72）由本线与 ares-modeling 按赛事 rubric 侧重分工：方法论深度归 ares-modeling，报告与呈现归本线。
