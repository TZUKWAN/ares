# ares-docx Word 生产规范

## 一、触发条件与输入

被 ares 总控或生产线技能在产出 Word 交付物时引用。输入：内容文本（来自生产线技能，已通过 ares-writing-style 自检）、文档类型（商业计划书/论文/技术报告/讲稿/QA 预案）、赛事特殊格式要求（来自 rubrics 的 deliverable_requirements）。

## 二、统一版式规范

| 项 | 规范 |
|---|---|
| 页面 | A4，上下 2.54cm，左右 3.17cm（Word 默认），装订边无需额外留白 |
| 封面 | 项目名（一号黑体居中）+ 副标题/slogan（三号宋体）+ 赛事/院校/团队/日期（四号宋体），下落三行排布 |
| 目录 | 自动目录域（Word 中 F9 或打开时更新），目录含三级标题 |
| 页眉 | 项目名，小五宋体居中，封面页不显示 |
| 页脚 | 页码（第 X 页 共 Y 页），小五宋体居中，封面不计页码 |
| 标题层级 | 一级 黑体 三号 段前段后 13pt；二级 黑体 四号；三级 黑体 小四；均左对齐、单倍行距、不入首行缩进 |
| 正文 | 宋体 小四（12pt），1.5 倍行距，首行缩进 2 字符，两端对齐；赛事 rubric 另有要求时按要求 |
| 图 | 编号 图{章号}-{序号}，图题居中置于图下方，五号宋体；图 300dpi 起 |
| 表 | 编号 表{章号}-{序号}，表题居中置于表上方，五号宋体；三线表优先 |
| 公式 | 居中独立成段，右侧编号 ({章号}-{序号})，变量斜体 |
| 参考文献 | GB/T 7714-2015 顺序编码制，五号宋体，悬挂缩进 |
| 英文数字 | Times New Roman |

页数/字数限制以赛事 rubrics/NNN.json 的 deliverable_requirements 为准，冲突时赛事要求优先。

## 三、执行步骤

1. 读取生产线的章节内容与 project.json（数字全部取档案）。
2. 调用 `scripts/make_docx.py` 的模板函数库构建文档（封面→目录→章节→参考文献→页眉页脚），或按本规范用 python-docx 自行组装（保持上表全部参数）。
3. 段落化正文写入（遵守 ares-writing-style：无小标题、无分点、无违禁词）。
4. 生成后运行本技能自检（第五节），并交给 ares-judge 复检。
5. 需要时导出 PDF（Windows 可用 Word COM，或用户在 Word 中另存）。

## 四、输出

`输出/项目名/` 下对应编号的 .docx 文件；长文档（计划书 30+ 节）分章生成后合并为单一文档。

## 五、质量自检清单

- [ ] 封面要素齐全；目录域存在（打开可一键更新）
- [ ] 页眉页脚页码正确，封面无页眉页码
- [ ] 标题层级样式与上表一致；正文宋体小四 1.5 倍行距首行缩进
- [ ] 图表编号连续且被正文引用；表用三线表；图不模糊
- [ ] 参考文献符合 GB/T 7714，正文引用上标 [n] 与文献表对应
- [ ] 全文数字与 project.json 一致（ares-judge 一致性扫描通过）
- [ ] ares-writing-style 机扫 0 违禁
- [ ] 满足赛事 rubric 的页数/字数/格式要求

## 六、与其他技能的协作接口

- 输入来自：九条生产线技能（内容）+ project.json（数据）。
- 讲稿类文档（路演讲稿）每页 PPT 对应一节，标注切换时机（加粗行内标注【切换到第N页】）。
- QA 预案按五类分组（技术可行性/数据真实性/竞品/财务/团队），问题加粗、应答要点正文段落（此文档类型允许疑问句，机扫时用 --allow-questions）。

## 七、样例脚本

`scripts/make_docx.py`：直接运行生成 `样例输出/ares-docx样例.docx`（含封面、自动目录、三级标题、段落化正文、图表编号、公式段、GB/T 7714 参考文献、页眉页脚页码），作为格式基准样张；其模板函数供各生产线 import 复用。
