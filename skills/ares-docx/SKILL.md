# Word 文档与版式

适用：需要 DOCX 的步骤。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 读取当前成果内容、规则和模板，按文档类型选择封面、目录、匿名、页眉页码、正文和引用格式。
2. 不强制所有作品使用商业计划书封面、口号、图表数量或章节数量；问卷、讲稿和论文分别排版。
3. 可以复用包内 scripts/make_docx.py 的文档组件；add_figure 需要真实图片与来源，不能插占位图。
4. 公式、表格和文字应可编辑，图表数据来自已验证结果；按当前体裁加载 ares-writing-style。
5. 生成后解析实际DOCX，再使用可用渲染器独立渲染并逐页查看；没有渲染能力时明确记录未验收版式。Windows Word 渲染器脚本仅在用户授权且不打断用户工作时使用。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
