# 软件原型与交互实现

适用：software 或明确需要原型的步骤。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 明确这是交互原型、演示系统还是生产实现，逐项列出实际实现与演示数据范围。
2. 页面数量、技术栈和架构由需求决定，不强制8页、多页或零构建。复用用户已有工程和环境。
3. 实现需要的真实数据流、状态与行为；演示数据明确标识，不将静态页面或死按钮称为完整功能。
4. 按验收行为运行对应测试，检查控制台、导航、表单、状态保存及必要的桌面/窄屏布局。
5. 截图必须来自真实页面；只有需要演示文稿时才做截图联动，不为满足统一门槛堆叠页面。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
