# 创新创业项目

适用：venture。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 按项目阶段区分创意、验证、实际经营；建立问题、方案、证据、价值与团队贡献的主线。
2. 技术指标、客户访谈、试点、订单、专利和营收逐项绑定原始资料。无成果就记录计划，不制造替代凭证。
3. 市场测算注明总体、范围、时间、方法和来源；预测参数交给 ares-finance，不能引用通用默认营收或融资。
4. 按当前赛道和作品选择计划书、财务模型、路演、答辩；只有项目确需时才增加软件原型。
5. 依据具体内容组织商业叙事，区分已实现、验证中、拟实施和估算。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
