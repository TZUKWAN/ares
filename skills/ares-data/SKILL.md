# ares-data 数据与实验数据规范

## 一、触发条件与输入

被生产线技能在需要数据支撑（市场测算、实验数据、问卷数据、财务数据可视化）时引用。输入：数据需求描述（量、维度、分布）、project.json 相关字段。

## 二、数据分析工作流（真实数据）

清洗（缺失/异常值处理留痕）→ 描述统计 → 建模分析（回归/聚类/因子/结构方程按选题）→ 可视化 → 结论回写 project.json。全过程脚本化，脚本可重复执行。

## 三、合成数据生成规范（无真实数据时）

1. 分布设定先于生成：明确每个变量的分布族与参数，写进脚本注释并与业务逻辑一致。
2. 随机种子固定（`numpy.random.default_rng(42)` 或等价），脚本可重复执行且结果一致。
3. 强制 DEMO 标注：数据文件头部与图表标题区注明 DEMO数据，提交前须替换为真实数据；交付清单同步登记进 data_confidence.estimated 或 placeholder。
4. 合成数据量满足分析方法要求（回归 n≥30、聚类 n≥100 等），不得为好看伪造过强规律。

## 四、图表风格统一

与 PPT 设计系统同色系（tech_blue #1F4E79/#2E75B6、eco_green #1E5E3A/#2E8B57、vitality_orange #C2531A/#E87D2B）；微软雅黑；标题含编号（图N-M）；导出 png（300dpi）与 svg 双份；坐标轴与来源标注齐全。

## 五、双口径说明

涉及 SPSS 的赛事（如市调大赛），同一份分析给出 SPSS 操作路径说明与 Python 脚本双口径，结论必须一致。

## 六、执行步骤与输出

1. 写分析脚本（Python，种子固定）→ 2. 产出数据文件（csv/xlsx）+ 图表（png/svg）+ 分析结论段（符合 ares-writing-style）→ 3. 重跑一次校验输出一致 → 4. 结论数字回填 project.json 并登记 data_confidence。

输出：`06-演示数据/`（或该线对应目录）下 data.csv|xlsx、analysis.py、charts/*.png|svg、README.md（DEMO 说明与复现命令）。

## 七、质量自检清单

- [ ] 脚本重跑两次输出逐字节一致（或浮点一致）
- [ ] 合成数据全部带 DEMO 标注并登记 data_confidence
- [ ] 图表配色与主题色一致、有编号与来源
- [ ] 分析方法与数据量匹配；结论有统计量支撑
- [ ] 结论数字已回填 project.json

## 八、协作接口

- 图表被 ares-ppt 引用时转为原生图表（数据入 project.json）。
- 分析脚本与数据被 ares-judge 一致性扫描覆盖。
- `scripts/demo_pipeline.py` 为标准样例（合成数据→统计→图表→重跑校验）。
