# 数据处理与图表

适用：数据相关步骤。输入来自当前步骤、项目事实、当届规则与前置实际产物。

## 执行要求
1. 保留原始数据和变量说明，记录清洗、缺失、排除与变换，保存可复现脚本。
2. 分析方法由研究设计与数据形态决定，不能机械规定样本量、模型组合或显著性结果。
3. 合成数据仅用于明确标识的演练/程序验证，必须记录生成规则与种子，不得进入正式调查或实测结论。
4. 图表由实际数据生成，明确坐标、单位、样本、区间和来源，避免混量纲或隐瞒不确定性。
5. 实际执行后回写领域事实与证据；脚本存在或有随机种子不等于已经运行成功。

## 与工作流衔接
- 当前会话有 ares_project / ares_library 时，先 status，再 open/read 当前步骤需要的能力。
- 按步骤 outputs 保存实际文件；check 后写真实内容复核记录，再 complete。失败记录原因并修复复测当前任务。
- 缺工具、数据、原文或人工结果时 block，不补造事实、不将计划当执行。
- 领域事实更新会使依赖结果需要复核。读取/安装技能不等于已经执行能力；本技能没有授予额外权限。
