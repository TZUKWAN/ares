# 版本、构建与许可

| 对象 | 当前编号 | 含义与准确内容 |
|---|---|---|
| DSH 主产品 | `2.3.0` | 根 `package.json`、`plugin.json` 的产品发布线 |
| 便携包和 MCP 适配器 | `2.4.0` | `platforms/packaging/`、MCP server 的跨平台适配发布线；共用当前主产品源码 |

本轮是独立修复分支，不新增发布标签，也不自动合并 `main`。两个发布线的编号保持明确区分。审核和本地验收以当前提交 SHA、实际构建收据及包文件清单为依据。

修改运行目录文件并不证明已打开的 DSH 进程载入了新版。浏览器模块和 Node 模块均可能仍持有旧实例；本轮不会操作用户窗口、重启宿主或通过修改全局配置强制加载。新版验收页面遇到旧后端报告时会明确拒绝把旧结果当作新版通过。历史原生回执与本轮真实宿主验收分别记录。
