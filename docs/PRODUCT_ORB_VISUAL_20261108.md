# 中央星体视觉修正

刘总否定前版网格作品投影，本轮仅修正中央图形与直接相关的比例、亮度和留白，直接修改运行版ARES。流程、作品数据、常驻原生聊天、验收和MCP机制不改；不操作用户窗口。

| 单元 | 文件与动作 | 验证与完成标准 |
| --- | --- | --- |
| V1 星体表面 | product-geometry、forge-renderer：取消线框叠页，使用带明暗、云层、边缘大气的实体蓝白星体，Canvas有真正的降级绘制 | 实际WebGL编译/绘制无错误；球体内部有连续表面，降级不是网格或静态图片；不新增虚假状态 |
| V2 视觉层次 | process-layout、forge-scene-controller：单阶段错位、球体与标题统一边界、节点/背景亮度收敛、前端缓存 | 单阶段窄长图和多阶段图均不出现叠网、过曝或标题远离图形；仍可点作品和阶段 |
| V3 实渲复核 | 自有隐藏浏览器、真实项目/文件/处理器，协议聊天槽位明确标识 | 1/9/40阶段、窄长单阶段、1920/1280/390截图人工查看；点击、输入草稿及原验收不变；真实Canvas绘制 |
| V4 边界审计 | 构建/语法/差异及修改前SHA核对 | 后端/原权限/验收/MCP与业务源不变；交付实际截图和对应结果，不能以测试通过代替视觉复核 |

风险控制：片元计算使用有界少量噪声，减少密集线条；遵从现有暂停和减少动态效果机制。星体动画是装饰性表面运动，不表示作品自动完成。新增shader保留兼容降级。只用实际渲染截图验看，不使用出图稿冒充已运行界面。


## 刘总追加要求

缩小星体，四周增加动态科技线条与流光。实体尺寸从1.32降到0.92（约小30%），由分层轨道而非大球体撑起画面；三条不同倾角轨迹具有遮挡关系、移动亮点与渐淡拖尾，配少量分段弧线和刻度。轨道是装饰，不写入任务或伪造Agent事件。当前暂停、减少动态效果及相机使用同一帧时钟 / 视角。后端、工作流及验收不改。
