## 风险与处理

- 历史规则文本不能凭来源 URL 或旧 confidence 认定为当届官方条款。缺少实际原文和范围时明确标记未核验，保留历史文字便于追溯。
- 真实宿主、模型和云账号测试依赖宿主实际能力及合法授权；协议夹具不能代替实际安装和在线调用。
- 浏览器回归串行执行，不对截图或大产物使用会生成巨量差异的深比较；只在任务自有目录保存证据。
- 第三方素材许可按原始许可证保留，公共源码许可不能覆盖其非商业限制。
