# ARES 全界面科幻工作台实施

目标：将现有现场的深空、冰蓝线框、琥珀反馈和状态动画贯穿运行版ARES，统一项目、流程、能力、作品、原生助手和操作面板。品牌仅ARES，常用操作中文直达。只改运行版，不改METIS、不重启DSH、不控制用户窗口；执行、真实验收、MCP隔离、金山协作、项目/版本数据格式保留。

| 最小单元 | 涉及文件 | 动作 | 对应验证与完成标准 |
| --- | --- | --- | --- |
| U1 外壳与组件 | app.js、ares-system.css、build_forge.mjs | 统一导航/搜索/按钮/表单/卡片/通知；真实项目/赛事/流程/能力的快捷跳转；统一短过渡 | 旧路由启动、实际搜索跳转、四页面加载、深色一致、无额外资源404 |
| U2 项目连续工作区 | project-workbench.js、ares-system.css | 当前节点/作品/操作并列；流程与真实版本同一时间轴，节点就地聚焦、版本沿用实际查看与对比；资料和事实入口简化 | 节点选择、实际文件、真实版本关联及对比、门禁保持、时间轴不改项目事实 |
| U3 流程画布 | app.js、ares-system.css | 可编辑节点画布、真实依赖线、拖动/键盘重排、直接编辑目标/能力/交付；模板引导与助手仍可用 | 增删/复制/拖动/键盘/依赖/技能绑定/保存草稿真实读回，错误依赖阻断 |
| U4 统一能力库 | app.js、project-workbench.js、ares-system.css | 技能、来源和当前项目子插件同一入口，能力卡展示用途/输入输出/启用/绑定/记录，沿用真实构建与参数执行 | 真技能读取与绑定、子插件构建/启用/节点绑定/参数/运行历史原链路，模拟来源不冒充真实调查 |
| U5 作品/助手/面板/动效 | artifact-viewer.js、forge-scene-controller.js、app.js、ares-system.css | 统一工具栏与侧面板、纸张原色、原生会话DOM保留；弹窗改上下文面板；动态开关及减少动态效果、窄屏/错误/空态完整 | 实际Markdown/PDF/HTML/编辑冲突、原生会话保持、焦点/ESC/Tab、手动降动效及OS设置、390/800/1440布局 |
| U6 复核与交付 | 相关既有测试、新对应DOM测试、说明、恢复状态 | 每单元通过后推进；最终主模型看实际截图、审计源码/打包、记录限制 | 旧路由可加载、资源自包含、后端核心SHA保持、所有对应失败修复、交付实际文件和日志 |

技术路线：重用原生JS/React桥接与现有真实数据API，新增统一CSS编译进既有workshop.css；新交互放既有app/project-workbench入口，不依赖已运行宿主新增路由。现场算法与展示事实分离，动效成功只依据真实状态；当前节点和历史版本不能因视觉选中而变成已验收。已有自定义流程/用户改动保留。

风险重点：原生组件的样式和焦点隔离；长流程/长文案与窄屏；大量渲染后的草稿/滚动/会话保持；新旧宿主路由兼容；减少动态效果与后台暂停。每项以自有headless运行真实生产处理器精准验证，不调用在线模型/金山，也不把协议夹具称为在线成功。

交付：运行版源码、可重复构建、对应测试与截图、实现/验证说明、源文件SHA审计、可恢复状态。当前用户窗口不代重载，不假称其已经加载。
