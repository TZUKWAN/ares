## 现在怎样使用

1. 「项目」中创建或切换参赛项目，可按项目或比赛名找项目；已有目录放在折叠入口。创建后直接进入项目现场。
2. 「赛事」显示当前比赛、赛道和届次，可查看规则材料或为另一比赛建项目。新建默认按所选比赛构建流程；采用已有自定义流程是明确展开后的选择。
3. 「本赛流程」读取当前项目的真实固定定义。编辑阶段目标、交付物、技能和依赖，预览实际新增 / 移除 / 需重验的影响，再“应用到这个项目”。全局基础流程库在设置的高级配置内。
4. 中央的织面文档投影代表整个项目作品集合，周围小星核代表阶段，人员代表真实登记队员或实际原生会话。点总作品看所有已声明作品及实际文件状态，点阶段看目标、作品、依赖和操作。左侧独立“项目航线”已撤去。
5. 阶段可安排一位牵头人及多个共同参与者；同一成员可以跨多个阶段。时间安排、工作登记和原验收仍可使用，人员配置不冒充在线编辑或实际完成。
6. 右侧本地 / 金山作品视图和常驻原生聊天保留。作品放大只由外层提供一个“返回项目”；编辑、保存、历史与协作仍跟随实际文件。底部只留项目、赛事、本赛流程、能力；维护操作进入设置。

字体按用途提高到正文15–16px、常用按钮14–15px、主要辅助说明12–13px；默认突出当前阶段，其他阶段按悬停 / 点选展示名称和详情，减少同时出现的文字与连线。

## 具体比赛的流程

`host/competition-flow.js` 为创新大赛高教主赛道、“挑战杯”学术科技三类作品及创业计划提供不同的建议工作安排，阶段、实际人工工作和产物均有实质差别。赛事通知是依据；ARES 的阶段名称、文件格式和编排方式是作者给出的可编辑准备方案，不冒称官方指定完整工作流。

- [教育部2026创新大赛通知](https://hudong.moe.gov.cn/srcsite/A08/s5672/202607/t20260731_1445670.html)：用于本赛身份、成员贡献与成果真实性等核对入口。
- [挑战杯2025官方章程](https://2025.tiaozhanbei.net/media/ckeditor_uploads/49/2025/06/13/1.%E2%80%9C%E6%8C%91%E6%88%98%E6%9D%AF%E2%80%9D%E5%85%A8%E5%9B%BD%E5%A4%A7%E5%AD%A6%E7%94%9F%E8%AF%BE%E5%A4%96%E5%AD%A6%E6%8A%80%E4%BD%9C%E5%93%81%E7%AB%9E%E8%B5%9B%E7%AB%A0%E7%A8%8B.pdf)：区分学术论文、社会调查和发明制作的工作安排；选了其他届次时明确标识参考届次未匹配。
- [第十五届创业计划组委会通知（赛事官网高校专区）](https://gaoxiao.tiaozhanbei.net/d1204/article/49690/)：据此加入2026年主体赛事8赛道；原“默认赛道”保留用于旧项目兼容，新建不再默认选择它。

没有专属方案的比赛，明确进入“确认本赛要求 / 确定作品与阶段”的起始草案，先读取真实规则和项目材料，再通过助手或人工编排形成项目流程。目录里的132项赛事不等于132套已经核验的完整方案；校省赛补充要求与本届提交细则仍需在项目内核对。

旧项目不会被自动换成新方案。可以在本赛流程的依据详情中重建起始草稿，或让助手依据真实材料完善，再审阅应用。已有版本和实际作品保持保留。

## 数据与执行机制

`host/project-flow.js` 提供项目专属读、草稿、预览与明确应用，绑定项目ID、比赛 / 赛道 / 届次 / 组别、原定义及修订号。固定技能正文和资源会核对并进入不可变包，避免全局技能变化或移除后丢掉旧项目依据。应用复用原冻结和升级逻辑；变化步骤须重新验收，旧定义 / 项目历史保留。

当前节点运行、未核对的运行记录、原生助手及其受管队友 / 后台任务未确认空闲时，不应用流程。原人工完成规则、内容复核哈希、模拟数据隔离及 MCP 约束保持。

主助手的原 `ares_workbench` 工具增加 `flow` 和 `flow-draft`：依原会话目录及固定定义门禁读取 / 保存建议。Agent不自动应用建议。界面按当前项目轮询建议，防止旧项目响应串入；采用建议或重建草稿时，人工旧草稿有本项目内的保留入口。

`host/project-product.js` 仅观察已登记产物路径的实际文件存在、大小及修改时间；章节另待检查，目录与文件分别表达。工作稿数量不作为比赛完成百分比，也不替代内容验收。队员新增 `collaboratorIds`，保留原牵头人，修改分工不改变验收状态。

中央作品投影为原创代码，参考 [Agent Display WORKS](https://github.com/cyberdaddyleo/agent-display/blob/main/README.md) 的多方贡献汇入总作品思路。未导入其模拟业务状态；阶段和贡献脉冲使用本项目实际记录，历史回放仍明确标识。WebGL与真实Canvas兼容路径均有实现，原自包含场景 / 字体入口继续使用。
