# 跨平台安装说明

Ares 以 Skills 为核心载体（各平台最大公约数），Commands/Agents/Hooks 为薄封装或辅助层。在不支持某类组件的平台上，用自然语言触发 Skills 即可，功能不打折。

## 通用前提

- Python ≥ 3.10，安装依赖：`pip install python-docx python-pptx openpyxl numpy matplotlib`
- 可选增强：`pip install playwright` 后准备 Chrome/Edge，用于原型运行时冒烟、截图和页面错误记录；`markitdown` 用于导入旧版 Word/PPT/PDF/XLSX 资料，缺少时不影响基础生产线。
- 本插件默认不依赖任何外部服务与网络（联网调研为增强项）。

## ZCode

1. 克隆本仓库到本地。
2. 将 `ares/` 目录复制或链接到 ZCode 插件目录（`~/.zcode/plugins/` 或工作区 `.zcode/plugins/`），重启会话。
3. `/Ares` 和六个 `/ares-*` 命令直接可用；或直接说「我要参加XX竞赛…」触发总控。
4. 低上下文模型首次运行先执行 `python ares/scripts/doctor.py --out ares-runtime.json`；正式交付追加 `python ares/scripts/validate_evidence.py project.json --strict` 与 `python ares/scripts/build_scorecard.py --profile project.json --output-dir 输出/项目名 --strict`。

## Claude Code

1. 克隆本仓库到本地。
2. 将 `skills/` 下全部目录挂载到 Claude Code 的 skills 目录（`~/.claude/skills/`，或项目 `.claude/skills/`），将 `commands/` 下的命令文件放入 commands 目录（可选）。
3. 数据与脚本目录保留在仓库原位（skills 内部以相对路径 `data/`、`scripts/` 引用；如移动了 skills，请将 `data/` 与 `scripts/` 一并复制到同层并保持相对位置）。
4. 用自然语言触发：「我要参加中国国际大学生创新大赛…」。

## Codex（AGENTS.md 指引方式）

在仓库根或项目根的 `AGENTS.md` 中加入一段：

```
## Ares 竞赛插件（插件根目录 = 本 AGENTS.md 所在说明中的 ares/ 目录，按实际安装位置解析）
当用户提出竞赛、参赛、备赛、商业计划书、路演PPT、原型、问卷等需求时：
1. 读取 ares/skills/ares/SKILL.md 并严格按其七步流程执行；
2. 数据只从 ares/data/ 与 project.json 读取，脚本用 ares/scripts/ 下工具；
3. 文本产出前先读 ares/skills/ares-writing-style/SKILL.md；
4. 只要单项产出（如只出 PPT/问卷/评审/同步）时，按对应技能（ares-ppt 等）的单项模式直接执行，无需走完整流程。
```

## DeepSeek Harness（DSH）

本仓库即 DSH bundle（根目录含 package.json + cordis.patch.yml + index.js），安装方式三选一：

方式一，专用 profile（推荐，隔离测试）：

1. 新建 `%DSH_HOME%\profiles\ares-dev\`（DSH_HOME 默认 `C:\Users\<你>\.dsh`），写入 package.json：

```json
{
  "name": "dsh-profile-ares-dev",
  "private": true,
  "dependencies": {
    "ares": "link:D:/METIS超级合并/ares"
  },
  "dsh": {
    "profile": {
      "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-headless", "ares"],
      "patchReload": "live"
    }
  }
}
```

2. 在该目录 `pnpm install`；
3. 冒烟：`dsh --profile ares-dev --dump-config`（应出现 `# == ares` 装配段）；`dsh --profile ares-dev "加载 ares 技能并执行 scripts/doctor.py"`。

方式二，并入既有 profile（同 metis-academic 的 desktop profile 装法）：在 profile 的 package.json 加 `"ares": "link:<本仓库绝对路径>"` 依赖、`dsh.profile.bundles` 数组加 `"ares"`，然后 `pnpm install`。

方式三，会话内安装：`plugin_manager { "action": "install_bundle", "target": "<本仓库绝对路径>" }`。

DSH 行为说明：16 个技能由宿主插件注册为 runtime skill，总控 ares 用户/模型双向可触发，生产线技能由总控按名调度；脚本执行用 pwsh（`python "<插件根>/scripts/xxx.py"`），信息采集与检查点用 ask_user_question；无 MCP 依赖（Ares 设计决策），缺 Python 时技能仍可加载、脚本调用 fail-closed。

## Kimi Code / Kimi Work / WorkBuddy 及其他平台

把本仓库放入工作区，在系统提示或首个请求中说明：

「本工作区已安装 Ares 竞赛插件（ares/ 目录）。处理竞赛相关需求时，先读 ares/skills/ares/SKILL.md 按其流程执行，写作纪律见 ares/skills/ares-writing-style/SKILL.md，数据与脚本在 ares/data 与 ares/scripts。」

平台如有 skills 机制则按各平台规范注册 skills/ 下 16 个目录；无 skills 机制则按上述自然语言指引加载，功能不打折。

## 验证安装

安装后对 Agent 说：

「读取 ares/data/competitions.json，告诉我 id 1 是什么赛事，然后运行 python ares/scripts/validate_rubrics.py 1 2 3」

期望返回：中国国际大学生创新大赛（A1 级），三份 rubric 校验全部 PASS。
