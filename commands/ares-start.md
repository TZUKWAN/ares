# /ares-start 全流程启动

## 用途

从一句话需求开始走完 Ares 总控七步流程：赛事匹配 → 加载赛事画像 → 一次性信息采集 → 建立 Project Profile → 生成生产计划 → 编排生产 → 质检交付。本命令是 skills/ares 总控技能的薄封装。

## 需要用户补充的信息（缺什么补什么，只问一轮）

1. 目标赛事（名称或别名，说不清就描述学科和赛事特征）
2. 项目名称与一句话简介
3. 赛道（不确定由 Ares 给候选）
4. 团队成员与分工、指导老师
5. 已有成果（专利/论文/试点/获奖，没有就说没有）
6. 真实经营数据（有则提供，无则按参数规则生成并标 DEMO）
7. 截止时间

## 参数说明

- 输入：一句自然语言需求（可含上述 1-7 任意组合）。
- 可选参数：`只出单项`（等价 /ares-bp、/ares-ppt、/ares-prototype）、`跳过提问`（缺项全部标 placeholder）。
- 输出：`project.json` + `输出/项目名/` 全套交付物 + 交付清单 + 数据真实性清单。

## 触发示例

- 「/ares-start 我要参加中国国际大学生创新大赛，项目是毫米波雷达独居老人跌倒监测，5人团队，2项专利，3个社区试点」
- 「/ares-start 帮我准备蓝桥杯，我目前只会基础DP，12周备赛」
- 「/ares-start 我们团队想做挑战杯学术作品的自然科学论文，题目是锂电池回收」
