# /ares-bp 只出商业计划书（含财务三表）

## 用途

基于已有 project.json（或先快速建档）只产出 01-商业计划书.docx 与 02-财务三表.xlsx，其余交付物不动。转发到 skills/ares-entrepreneurship 的步骤 1-3。

## 需要用户补充的信息

- project.json 路径（默认当前工作目录）；没有档案时给项目一句话简介即可，Ares 先建档再产出。
- 财务参数覆盖项（可选）：起始年营收、增长率区间、利润率倍数、融资金额与出让比例；不给则按默认规则（185-255 万 / 25%-40% / ×1.13-1.4 / 400 万出让 10%-25%）。

## 参数说明

- 输入：project.json（必需或先建档）、财务参数覆盖（可选）。
- 行为：按 references/bp-outline.md 十章引擎逐节生成 → build_financials.py 出三表 → 写作纪律机扫 → 一致性扫描。
- 输出：`输出/项目名/01-商业计划书.docx`、`输出/项目名/02-财务三表.xlsx`。

## 触发示例

- 「/ares-bp 按现在的档案出商业计划书」
- 「/ares-bp 起始营收改成 230 万，融资 500 万出让 20%」
