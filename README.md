# Ares 超级竞赛插件

Ares 是一个面向大学生学科竞赛与创新创业竞赛的超级插件，适配 Claude Code / Codex / Kimi Code / Kimi Work / WorkBuddy / ZCode / DeepSeek Harness 等各类 Agent 平台。

用户加载插件后，只需一句话需求（如"我要参加XX竞赛，项目是XXX"），即可一次性产出该赛事所需的全套材料：商业计划书/论文/设计文档（Word）、路演/答辩 PPT（PPTX 程序化生成）、可交互作品原型（多页 HTML 前端系统）、财务三表（自动勾稽校验）、源代码、实验数据、讲稿与答辩预案、模拟评审报告等。

## 能力总览

| 生产线 | 技能 | 覆盖范围 |
|---|---|---|
| L1 创业竞赛线 | ares-entrepreneurship | 中国国际大学生创新大赛、挑战杯创业计划、电商三创、iCAN、创青春、服务外包、学创杯等 |
| L2 理科建模线 | ares-modeling | 全国/美国数学建模、统计建模、数学竞赛、物理/化学/生物实验创新等 |
| L3 工科作品线 | ares-engineering | 电子设计、机械创新、结构设计、智能汽车、机器人、节能减排、嵌入式、物联网等 |
| L4 商科分析线 | ares-business-case | 市场调查与分析、会计商业案例、税收风险案例、金融科技、企业竞争模拟等 |
| L5 艺术设计线 | ares-art-design | 广告艺术、华灿奖、工业设计、数字艺术设计、建筑设计等 |
| L6 程序算法线 | ares-coding-contest | ACM-ICPC、蓝桥杯、百度之星、CCPC、天梯赛、AI算法精英赛等 |
| E1 人文语言模块 | ares-humanities | 外研社系列赛、21世纪杯、韩素音翻译、诵写讲、版权征文等 |
| E2 实验技能模块 | ares-lab-skills | 金相技能、医学技术技能、地质技能等（训练材料，非代替动手） |
| E3 模拟经营模块 | ares-simulation | 企业竞争模拟、数智化经营沙盘、学创杯等（决策模型+策略手册） |

共享技能：`ares`（总控路由）、`ares-writing-style`（写作纪律）、`ares-docx`（Word 生产）、`ares-ppt`（PPTX 程序化生成）、`ares-data`（数据与实验数据）、`ares-prototype`（多页 HTML 原型）、`ares-judge`（模拟评审与质检）。

内置数据：132 项赛事主库（`data/competitions.json`）、赛道映射（`data/tracks.json`）、132 份专属评审标准档案（`data/rubrics/001.json` … `132.json`）。

低上下文运行先执行 `scripts/doctor.py` 记录本机能力，再由 `scripts/match_competition.py` 做目录内确定性匹配；`run_state.py` 保存断点，`build_scorecard.py` 生成评分点→证据→产物覆盖矩阵。正式申报还必须通过 `validate_evidence.py --strict`，缺少原文摘录、内容哈希、评分引用或实际产物引用时直接阻断。

要求第三方检测、查新报告、合同订单、真实营收或一手调研的评分点，还必须绑定 real/强来源证据；DEMO 或 AI 估算只会进入缺口矩阵，不会被算作正式覆盖。

入口回归可用 `scripts/smoke_low_context.py`：它只串联真实状态文件、赛事目录、环境报告和已有档案门禁，不模拟模型能力，也不生成虚假参赛材料。

已有旧项目先运行 `scripts/migrate_profile.py` 生成迁移缺口报告；报告只列出需要补原始凭证、来源和产物引用的地方，不会自动填充虚假内容。

评分矩阵有未覆盖项时运行 `scripts/build_evidence_request.py`，会生成按评分点分类的证据补交清单和 claim 模板，帮助团队补材料后重新过严格门禁。

正式交付只需运行 `scripts/final_gate.py`；它会串行执行所有必需门禁并生成《最终门禁报告.json》，任何失败都返回非零状态。

## 自然语言触发示例

插件已加载的情况下，以下说法均可直接触发（无需记忆任何命令）：

1. 「我要参加中国国际大学生创新大赛，项目是毫米波雷达独居老人跌倒监测，帮我出全套参赛材料。」
2. 「帮我准备今年的全国大学生数学建模竞赛，往年的A题给我练一套完整的论文加代码。」
3. 「我在准备挑战杯创业计划大赛，路演PPT帮我做一份，8分钟版。」
4. 「给我这个项目做一个可演示的原型，多页面的那种，评委能点来点去。」
5. 「我是市场营销专业的，想参加全国大学生市场调查与分析大赛，帮我从头到尾规划并产出。」
6. 「我报了蓝桥杯，帮我排一个12周的训练计划，带题库和模板代码。」
7. 「商业计划书里的营收数字改了，把 PPT、财务表、讲稿里所有相关数字同步更新。」
8. 「像评委一样评审一下我的计划书，按国赛的评分维度打分。」

## 快捷命令

| 命令 | 用途 |
|---|---|
| `/Ares` | 稳定总入口：低上下文模型按阶段断点执行全流程 |
| `/ares-start` | 全流程启动：赛事匹配 → 档案建立 → 生产计划 → 编排生产 → 质检交付 |
| `/ares-bp` | 只产商业计划书（含财务三表） |
| `/ares-ppt` | 只产路演 PPT（基于已有 project.json） |
| `/ares-prototype` | 只产多页 HTML 原型系统 |
| `/ares-review` | 只做模拟评审与一致性扫描 |
| `/ares-sync` | project.json 变更后全量同步重算 |

在不支持命令的平台上，直接用自然语言说出对应需求即可，功能不打折。

## 核心工作方式

单一事实源：所有产出物从同一份 `project.json`（Project Profile）生成。档案建立后，商业计划书、PPT、财务三表、原型、讲稿全部从它读取数据；改档案后执行同步即可全量重渲染，保证各材料数字一致。

诚信护栏：所有模拟数据强制标注 DEMO；每单交付附《数据真实性清单》（用户提供真实数据 / AI估算 / 占位待填 三类）；严禁虚构专利号、获奖记录、合作协议等可核查事实。

## 安装

见《跨平台安装说明.md》：ZCode 插件目录直装；Claude Code 挂载 skills 目录；Codex 用 AGENTS.md 指引；其他平台自然语言触发。

## 能力边界

- 不代考、不代赛：程序算法线与实验技能模块只产出训练与备赛辅助材料。
- 不联网抓取付费数据库：市场与政策数据以公开权威来源为准，产出时标注来源与年份。
- 财务预测为参数化模型推演，提交前须按真实经营数据校准。
- 论文类产出不保证查重与 AIGC 检测通过，交付时会提示相关风险。
